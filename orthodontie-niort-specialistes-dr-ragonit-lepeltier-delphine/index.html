Le cabinet

Le praticien définira les mouvements nécessaires pour obtenir le résultat final. La fabrication des aligneurs pourra être débutée et le traitement pourra commencer.

Le cabinet utilise la solution Dental Monitoring pour assurer un suivi rapproché de votre traitement. Le système Dental Monitoring permet de contrôler l’évolution du traitement orthodontique par le biais d’une application personnalisée et d’une scan box.

Pour la mise en place de ce monitoring, il faut installer l’application Dental Monitoring sur votre smartphone. Grâce à cette application vous scannerez vos dents. Le scan est ensuite transmis sur une plate-forme sécurisée.

Cela nous permettra d’évaluer l’évolution du traitement et de communiquer avec vous sur le traitement (changements d’aligneurs, d’elastiques, verification d’hygiene, urgences )
